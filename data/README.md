# Example datasets

These datasets are built into SEMbada: open the home screen and choose **Open example** on a model. The model, construct names, definitions, and analysis settings (multigroup analysis, IPMA, moderation, higher-order constructs) are set up automatically. The CSV copies in [`examples/`](examples) are provided for use in other software and to show the expected file format. [`samples.json`](samples.json) is the bundle that the app embeds, and [`sample.csv`](sample.csv) is the data behind *Try the sample data*.

**Licences.** The real datasets are taken from the R packages seminr, cSEM, and plspm, which are licensed under GPL-3; please cite the original sources when you use them. The simulated datasets were generated for demonstration (see [`../tools/make_samples.py`](../tools/make_samples.py)) and do not describe any real population.
